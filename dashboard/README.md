# 🏦 Smart Banking Analytics & BI Project

## 📌 Project Overview
This phase of the project represents the **Data Analysis & Business Intelligence** component of a comprehensive banking system. The primary goal is to transform cleaned data (processed during the ETL phase) into actionable insights that assist management in decision-making, fraud detection, and branch performance monitoring.

## 🛠️ Technologies Used
* **Database:** PostgreSQL (for data ingestion and Star Schema implementation).
* **Query Language:** SQL (for developing 10 complex analytical queries to extract KPIs).
* **Data Visualization:** Power BI (for Data Modeling and designing 5 interactive dashboards).

## 📊 Key Accomplishments (Deliverables):
1. **Data Ingestion:** Successfully imported cleaned CSV data into the operational PostgreSQL database.
2. **SQL Analytics:** Authored and documented 10 analytical SQL queries addressing core business questions (e.g., Top Customers, Fraud Rate, Defaulting Loans).
3. **Data Modeling:** Successfully built a robust Star Schema within Power BI, resolving circular dependencies to ensure accurate cross-filtering.
4. **Interactive Dashboards:** Designed 5 specialized dashboards:
   * **Executive Dashboard:** High-level overview of revenue and core KPIs.
   * **Customer Dashboard:** Demographic analysis and top-spending customers.
   * **Branch Dashboard:** Comparative performance analysis across branches.
   * **Fraud Dashboard:** Detailed analysis of fraudulent transactions (tailored for AI model training).
   * **Loan Dashboard:** Monitoring loan types and active/defaulted status.
